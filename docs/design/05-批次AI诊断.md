# 05 批次横向 AI 诊断

版本：v0.1（2026-09-02）  
对应计划：[../plan/迭代6.1-多维度AI诊断与标定引擎.md](../plan/迭代6.1-多维度AI诊断与标定引擎.md)

> 辅助分析层。正式通过/失败仍只看硬断言与批次聚合，诊断结果不得改写 verdict、pass_rate、断言、Skill 文件或容差。

---

## 1. 定位

迭代 6 已提供 `repeat_count`、方差统计和 `reports/batches/<batch_id>/summary.json`。6.1 在此之上增加一次**手动**横向诊断：

```text
BatchResult + 压缩子 Run + Skill 原文
  → Batch AI Analyst（LLM）
  → reports/batches/<batch_id>/ai_diagnostics.json
  → 控制台 Batch 面板（查看 / 复制 Patch）
```

非目标：自动写回 Skill、GIS 拓扑诊断、单次 Run 深度诊断、诊断历史版本、DB schema 变更、batch 完成时自动分析。

---

## 2. 数据模型

定义于 `geoskillbench.models.batch`：

- `SkillPatchSuggestion`：`skill_id` / `target_file` / `diff_content` / `explanation`
- `BatchAIDiagnostics`：`batch_id` / `created_at` / `source` / `model` / `summary_text` / `attribution_breakdown` / `root_cause_analysis` / `suggested_patch` / `error`

`source`：

| 值 | 含义 |
|---|---|
| `llm` | 模型返回且归因校验通过（未知 key 或和不在 0.99~1.01 时归因降为 `{unknown: 1.0}`） |
| `unavailable` | 模型不可用或输出无法解析；无归因百分比、无 patch |

归因枚举（冻结）：

- `skill_prompt_issue`
- `agent_drift`
- `env_error`
- `assertion_or_scenario`
- `harness_variance`
- `unknown`

---

## 3. 输入与 Patch 门控

Analyst 输入（`assemble_analyst_input`）：

1. 批次聚合：通过率、verdict / operational 分布、entropy、工具频次、耗时分布。
2. 子 Run 压缩：工具名序列、失败断言、工具错误、judge issues；优先失败 run，最多 20 条。
3. Skill 原文：由 batch 关联 scenario 的 `skill.path` 读取。

Patch 仅在同时满足时生成：

- 批次只定位到**一个** Skill 文件
- `skill_prompt_issue >= 0.4`
- LLM 给出基于原文的完整文件内容，后端用 `difflib.unified_diff` 生成真实 diff

后端**不写** `skills/`。`unavailable` 与非 Skill 主因均不出 patch。

---

## 4. API

| 方法 | 路由 | 语义 |
|---|---|---|
| `POST` | `/api/batches/{batch_id}/analyze` | 手动触发。运行中 409；无 `summary.json` 404；LLM 失败写占位文件后 502（`detail` 为诊断对象）；成功 200。重复调用覆盖写盘。 |
| `GET` | `/api/batches/{batch_id}/diagnostics` | 读 `ai_diagnostics.json`；未分析 404。 |

产物路径：`reports/batches/<batch_id>/ai_diagnostics.json`。不改 `batches` 表。

可选查询参数 `model`；缺省取 `models.yaml` 第一个别名，再回落到 `deepseek-v4-flash`。

---

## 5. 前端

控制台不做顶部导航重构。面板顺序：Scenario → Task Progress → Batches。

- Scenario：`Repeat` +「创建批次」→ `POST /api/batches`，并订阅 `/api/batches/{id}/events`
- Progress：批次执行时显示第 N/M 轮、已完成数、当前子 run 阶段（卡片，不展示 JSON 墙）
- Batches：列表、方差统计卡片、工具覆盖、子运行
- `BatchAnalystView`：简报、归因条、Diff + 复制、根因 Tab
